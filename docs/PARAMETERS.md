# GeoConflictModeler Parameter Guide (Quick)

Full web guide: `site/parameters.html`

## Key ideas
- MC = adjudicator (truth)
- Chess = decision layer (bounded influence)
- Battle Losses = cinematic run snapshot

## High-level knobs
- **Year**: baseline modernization assumptions
- **War Mode / Intensity**: tempo multipliers
- **Sim Horizon**: max days
- **Nukes**: rare macro-shock toggle
- **Core Model**: Cinematic / Dense / Integrated
- **Scenario Type**: biases domain mix
- **Battleground**: theater anchor (geography-aware)
- **Sanctions**: economic friction
- **Iterations / Seed**: Monte Carlo quality + reproducibility
- **Duel plies / depth**: chess pacing + strength tier
