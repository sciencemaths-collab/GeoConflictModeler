Parameter Guide

What each control means, how it affects the Monte Carlo adjudicator, and how chess influences (without overriding) outcomes.

Core philosophy

  • Monte Carlo = adjudicator (truth). Probabilities are derived from stochastic trials.
  • Chess = decision layer (influencer). Chess evaluation can optionally nudge Blue-vs-Red odds slightly, bounded by draw probability.
  • Battle Losses table = cinematic run. A single storyline is used for concrete totals and “today” deltas.

Mixed-theater override (advanced)

If you enable the theater mix override, you can force how the model allocates emphasis across air/sea/land. This is helpful for “what-if” explorations.

Understanding outputs

  • Win mix shows Blue/Red/Draw probabilities. Fresh sessions start at 50/50/0 until you run.
  • Phase separation visualizes uncertainty: strong winner + low draw = clean layers; high draw keeps mixing.
  • Battle Losses are based on one cinematic storyline (not the percentile bands).
