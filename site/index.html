What it is

A visually driven, educational toy model for exploring how assumptions (theater, friction, sanctions, readiness, escalation) reshape outcomes under uncertainty.

Geography-aware
theater anchor + distance/friction effects built into the campaign engine

Online-ready
login + Stripe subscription gate available

Monte Carlo (Truth)

Runs many stochastic trials to estimate Blue/Red/Draw and distributions of losses/duration.

Chess (Decision)

Generates synchronized strategic moves and an evaluation signal used as a small evidence term.

Cinematic Run

Produces a concrete storyline for the Battle Losses table (and daily deltas).
